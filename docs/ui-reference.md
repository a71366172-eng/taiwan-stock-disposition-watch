# UI 改版設計基準

使用者提供的三張截圖已一併保存在本目錄，作為本次改版與後續調整的設計基準。截圖中的股票與數字僅供視覺參考。

## 參考截圖

1. [風險清單單列樣式](ui-reference/risk-row.png)：單列股票代號、名稱、市場、收盤價與漲跌；中段顯示風險提示與累計門檻進度，右側顯示量能／週轉等數據及自選操作。
2. [風險總覽卡片](ui-reference/risk-overview-panels.png)：以深色卡片分組展示首次／再次處置試算、當日進入處置名單、近期公告自結與即將出關日期。
3. [處置股清單](ui-reference/disposition-list.png)：深色全寬清單，提供首次／再次處置、上市／上櫃、股期等篩選、排序、搜尋、列表／格狀切換；列內顯示股票資訊、處置類型、公告區間、剩餘天數與市場數據。

## 改版方向

- 整體採深色交易終端風格：石墨灰背景與卡片、細邊框、緊湊資訊密度；藍色用於導覽與可操作項目，紅／綠區分漲跌，黃／橙標示風險與首次處置，紅色標示再次處置。
- 股票列表改成橫向緊湊列，將主要欄位放在同一視線：股票、價格／漲跌、處置風險或公告期間、剩餘時間、市場指標、自選按鈕。桌面版善用寬度，手機版允許卡片化或橫向捲動。
- 風險總覽以分區卡片呈現首次／再次處置預測、當日可能進入處置的股票、近期公告及即將出關名單；列表中的累計進度需連到實際計算結果。
- 處置股頁增加篩選、搜尋、排序和列表／格狀檢視，讓使用者能迅速依處置次數、上市／上櫃與到期時間找股票。
- 以資料快照與交易所公告為準；預測、公告事實和估算指標要在視覺上清楚區分。期間漲跌、剩餘日數與門檻進度都需標出計算基準。

## 後續實作提醒

- 截圖內的股票、價格、門檻比例、日期及預測結果只是參考圖內容，不可當成即時資料或直接寫死在介面中。
- 風險排序與門檻進度應使用目前資料模型及規則計算，不從圖片抄數字。
- 參考圖雖出現「最快 3 天」等文案，首頁仍依既有需求定位為「注意股」；不必特別把三日預測期間做成頁面主標題。
- 真正改版時先沿用現有上市／上櫃資料與正式處置公告來源，再逐步調整視覺層，不改變預測含義或官方資訊標示。
